## 📞 SUPPORT

### If .env Generation Fails
```bash
# Option 1: Try manually
cp .env.example .env
nano .env

# Option 2: Use template from ENV_QUICK_REFERENCE.md
```

### If Database Connection Fails
```bash
# Check PostgreSQL is running
psql --version
psql -U charlady -d charlady_db

# Check DATABASE_URL in .env
grep DATABASE_URL .env

# Update .env with correct credentials
```

### If M-Pesa Connection Fails
```bash
# Check credentials in .env
grep MPESA_CONSUMER .env

# Test with curl
curl -X GET "https://sandbox.safaricom.co.ke/oauth/v1/generate?grant_type=client_credentials" \
  -u "your_consumer_key:your_consumer_secret"
```

### If Django Check Fails
```bash
# Run with verbose output
python manage.py check --verbose

# Check settings are loaded
python -c "from django.conf import settings; print(settings.DEBUG)"
```
